# VSCXML Marketplace

Claude Code plugin marketplace for VSCXML state machine tools.

## Installation

```bash
/plugin add-marketplace https://github.com/miho/vscxml-marketplace
/plugin install vscxml
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| **vscxml** | W3C SCXML editor, simulator, and code generator (Java, JS, C#, C, Python, Go, ST) |

## Skills

| Command | Description |
|---------|-------------|
| `/vscxml:design` | Create and visualize state machines from descriptions |
| `/vscxml:simulate` | Test with event injection, tracing, live highlights |
| `/vscxml:generate` | Generate code for 7 targets |
| `/vscxml:trace` | Record, compare, and replay execution traces |

Plus 49 MCP tools for fine-grained control. See [vscxml.com](https://vscxml.com) for details.
